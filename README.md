## Podsumowanie zadania 

Pracowałem na zbiorze danych `titanic.csv`.
Udało mi się stworzyć **python recipe**, którego zadaniem było:
- przygotowanie danych
- podział danych na zbiory dla modelu
- następnie wytrenowanie modelu (Random Forest)
- ewaluacja modelu
- zapis do wynikowego datasetu

# Repozytorium zawiera

- `/code/model.py` - recipe z *dataiku*
- `/data/titanic.csv` - zbiór danych na którym pracowałem
- `/screenshots/flow.png` - przedstawia flow projektu
- `/screenshots/output_dataset.png` - przedstawia zbiór powstały w wyniku działania *recipe*
- `/screenshots/project_main_page.png` - przedstawia stronę główną projektu
- `/screenshots/recipe_job_succeeded.png` - przedstawia wynik uruchomienia *recipe*
- `/screenshots/recipe_logs.png` - przedstawia logi zawierające metryki wymagane w zadaniu
- `/model_summary.md` - zapis metryk z logów
- `/README.md` - opis projektu (ten plik)
